# localqueue v1.4.0

## Typed handler contexts

EventBus handlers can now receive a typed `HandlerContext` subclass. Configure
`EventBus[AppContext](..., context_factory=...)` to add application-owned
dependencies explicitly while retaining autocomplete and static checking.

Factories may be synchronous or asynchronous and run once per delivery
attempt. Factory failures use the existing retry and dead-letter policy; the
handler is not invoked for a failed factory. Contexts expose read-only
`event_id`, `attempt`, `handler_name`, and `publish()` runtime capabilities.

The EventBus does not manage dependency lifecycles. Existing one-argument
handlers remain compatible and receive no required migration.
